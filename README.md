# Last Mile Delivery Route Optimization Platform

## Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Spring Security
- Swagger
- Maven

## Features
- User CRUD
- Role-based system
- REST APIs
- Swagger Documentation
